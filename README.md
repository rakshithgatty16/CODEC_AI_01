# Weather Data Analysis and Temperature Prediction

## Overview

Weather Data Analysis and Temperature Prediction is a Machine Learning project that analyzes historical weather data and predicts temperature using weather-related parameters such as humidity, wind speed, and atmospheric pressure.

The project includes a user-friendly Flask web application that allows users to input weather conditions and receive predicted temperature values instantly.

## Features

* Weather Data Analysis
* Data Cleaning and Preprocessing
* Temperature Trend Visualization
* Machine Learning-Based Prediction
* Flask Web Application
* Responsive User Interface
* Real-Time Temperature Prediction

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-Learn
* Matplotlib
* Seaborn
* Flask
* HTML
* CSS

## Dataset

The dataset contains:

* Date
* Temperature
* Humidity
* Wind Speed
* Pressure
